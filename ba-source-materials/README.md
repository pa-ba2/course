# Business Analytics — Source Reference Pack

Flat markdown export of BA1's recap and BA2's original (pre-redesign) content, for use as reference material in a Claude Code project.

## Contents

| File | What it is |
|---|---|
| `ba1-recap.md` | Condensed recap of BA1 (11 weeks → one reference doc) |
| `ba2-week-00.md` … `ba2-week-10.md` | Original BA2 deck content, one file per week, extracted from slides |
| `ba2-final-project.md` | Original BA2 final project brief |
| `curricula-mapping.md` | BA1's official week-by-week topic titles (planning sheet) |
| `PROJECT-SETUP-PROMPT.md` | Paste into Claude Code as your first message to kick off the project |

## Notes on the extraction

- BA2 files were extracted from PDF slide exports with `pdftotext -layout`; layout/spacing is approximate, and `---` marks slide boundaries.
- These are **text only** — no images, charts, or diagrams from the original slides are included. The original `.pptx`/`.pdf` files remain the source of truth for visuals.
- `ba1-recap.md` was hand-authored from a longer illustrated guide; diagram descriptions are kept as captions where the original had a visual.
